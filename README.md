# Project Description:
CareerConnect is a web-based platform designed to help job seekers organize and manage their job search activities in one centralized place. The platform enables users to create professional profiles, manage resumes, discover job opportunities, submit applications, and track their progress throughout the recruitment process. Job seekers will create profiles, manage resumes, search and apply for jobs, and track application progress. Recruiters will create and manage job postings and interact with potential candidates.

# Identified Problem:
Job seekers reply on multiple latofrms and tools to manage their job search. This process can make it difficult to stay organzied and/or maintain an accurate overview of application progress.

# Proposed Solution:
CareerConnect provides a centralized web-based platform that brings all related job-search activities together in one system.
